# You can also see finance_db/supabase.md for a quick reference table on switching modes!

# === Production (Supabase) Connection ===
psql postgresql://postgres:[YOUR_SECRET_PASSWORD]@db.xihtrwadyqfimillpxff.supabase.co:5432/postgres?sslmode=require

# Replace [YOUR_SECRET_PASSWORD] with your actual DB password from the Supabase dashboard (Project > Database > Connection info).

# Recommended (Backend): Set this connection string in your app's `.env` as:

# === Local Development Connection (Dev Only) ===
# If you wish to run a local Postgres for offline/dev testing, use:
psql postgresql://appuser:dbuser123@localhost:5000/myapp

# Or set in your .env or via export, as:
#   POSTGRES_URL="postgresql://appuser:dbuser123@localhost:5000/myapp"
#   POSTGRES_USER=appuser
#   POSTGRES_PASSWORD=dbuser123
#   POSTGRES_DB=myapp
#   POSTGRES_PORT=5000

# Switch between environments by updating your .env, or by `source finance_db/db_visualizer/postgres.env` (then start your backend).
